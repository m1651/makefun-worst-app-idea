Entry for the make.fun bounty [The Worst App Idea Ever Pitched](https://make.fun/bounty/u-plucky-sparrow-67-the-worst-app-idea-ever-pitched-a0396b23): one sentence pitching the worst, most useless app imaginable.

## The entry

> SockSort AI scans your laundry, pairs every sock, then charges $4.99 a month to text you daily reminders that the one sock it could not find is definitely still in the house somewhere.

(184 characters, one line.)

## How it works

`main.py` (Python 3, standard library only, no network) writes the pitch to `/output/entry.txt`. Before writing, it enforces the competition gate in code: the text must be non-blank, a single line, and between 1 and 240 characters long, exiting with an error if any check fails.

Run it with:

```sh
python3 main.py
```
